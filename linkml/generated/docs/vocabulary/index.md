# The vocabulary of the Pruzhany record

The vocabulary of the record as LinkML enums, one a group, each value with its definition and the RiC-O, EHRI or declared local term it means. Generated by vocabulary/generate.py from vocabulary/sourced-entities.json (1.3.0, released), vocabulary/site-content.json (1.0.0, released), vocabulary/reading-status.json and vocabulary/identifiers.json; never edited by hand.

URI: https://pruzhany.org/ns/vocabulary
