# Contributing

Report a model error or ask a question in
[this repository's GitHub issues](https://github.com/dsmedia/pruzhany-schema/issues).
Describe the type, field and expected meaning, with a small fictional example.
This repository and its issues are public: do not include information about real people.
Follow the [issue conventions](docs/agents/issue-tracker.md) and
[triage labels](docs/agents/triage-labels.md); maintainers triage requests before implementation.

For setup and checks, follow the [README quick start](README.md#quick-start).
Propose a focused pull request explaining the change and its validation.
Before merging, maintainers review it and require the repository checks and
[consumer checks](docs/agents/verification.md#consumer-checks).

New vocabulary types need the owner's batch approval with their mappings under the
[vocabulary approval process](docs/vocabulary-approvals.md); until then use `other` with `proposed_type`.

AI agents work from [AGENTS.md](AGENTS.md). The licence is being settled.
